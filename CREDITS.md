## HD textures

Made with these open upscaling models:

| Model | Author | Licence |
|---|---|---|
| 4x-PBRify_UpscalerV4, 4x-PBRify_RPLKSRd_V3 | [Kim2091](https://github.com/Kim2091/Kim2091-Models) | CC0-1.0 |
| 4x-UltraSharp, 4x-UltraSharpV2 | [Kim2091](https://huggingface.co/Kim2091) | CC-BY-NC-SA-4.0 |
| 4x_foolhardy_Remacri | foolhardy ([mirror](https://huggingface.co/FacehugmanIII/4x_foolhardy_Remacri)) | CC-BY-NC-SA-4.0 |
| 4xTextures_GTAV_rgt-s (and dither), 4xNomos8kSC | [Phhofm](https://github.com/Phhofm/models) | CC-BY-4.0 |

The upscaling ran on [PyTorch](https://pytorch.org) and [spandrel](https://github.com/chaiNNer-org/spandrel).

Because some of these models are licensed for non-commercial use only (CC-BY-NC-SA-4.0), this project is free, and it stays free.
