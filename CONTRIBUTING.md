# Helping out

Thanks for wanting to help! This is an early test build, so real players trying it is the most useful thing there is.

## The one rule

**Never post game files** anywhere in this project: no disc images, no files from the disc, no built game, no extracted textures, sound or movies. Screenshots, videos of the game running, and logs are fine. Issues that include game files will be removed.

## 1. Test your disc version

So far the app knows one version of the disc (title ID 56550028, `default.xbe` SHA-1 `c2c8aafabefb2ad671fb709f61526bfdb4868f9d`). If yours is a different version, the app says so. Open a ["My disc isn't recognised"](../../issues/new/choose) issue with what it shows. That's all it takes to get another region or printing added.

## 2. Report bugs

Press **F11** while the problem is on screen, then open a [bug report](../../issues/new/choose) and attach the files it saves. Say where you were, what you expected, and which settings you changed. Problems that only show up after a long session are especially useful, because automated test runs can't reach them.

## 3. Play-test and tell us how it went

Even "I played through three levels and it was fine" helps. So does "the install was confusing at this step".

## 4. Code

The port is built on [Recompose](https://github.com/Joshspeakman/recompose). Fixes that help every Recompose game belong there. If you'd like to work on this port itself, open an issue first so we can talk it through.
